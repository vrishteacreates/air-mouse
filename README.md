# Air Mouse 🖱️

A gesture-controlled virtual mouse using Python, MediaPipe, OpenCV and PyAutoGUI.

## Features
- Real-time hand tracking
- Cursor movement using index finger
- Left click using thumb and index finger pinch
- Webcam-based detection

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Installation

pip install -r requirements.txt

## Run the Project

python airmouse.py

Press Q to exit.
